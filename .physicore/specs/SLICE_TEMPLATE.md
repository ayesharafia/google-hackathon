# Task specification: one vertical slice

Status: PROPOSED, not scientific approval.

## Evidence / actual use case
Who uses it, problem, measured or sourced priority, reference files/URLs/dates. Separate assumed vs observed user needs.

## Acceptance
Visible workflow, inputs, outputs, error paths, failure behavior, exact reproducible checks. Non-goals.

## Domain and physical fidelity
If simulation: equations, boundary/initial conditions, units, approximations, solver/backends and version, valid range, benchmarks and appropriate tolerance justification. Else state NOT APPLICABLE.

## Approval boundary and rollback
What this task may autonomously change; what needs human/expert approval; how changes are reverted.

## Test plan
Smallest repeatable test commands, data fixtures, expected behavior, known uncertainty or disabled tests.
