## Assessment keys

- **T**: Existing Optima/Candara display and neutral body roles retained. No new font, stock pairing, wordmark, ornamental emphasis or mono label costume. Exact dates/counts/progress use tabular figures and readable spacing.
- **M**: Existing tonal green/ink system; no new glow, gradient, texture, glass or shadow. Actual review corrected selected-button pale text to dark ink; final browser assertion checks at least 4.5:1 contrast. Pending/disabled states retain existing native behavior.
- **I**: All new buttons/disclosure/pagination/recovery/navigation respond to actual clicks; keyboard Enter refresh and focus restoration checked. Context guards reject stale/detached actions. Immediate linked selection has purpose; no entrance reveal, underline wipe, boop, decorative float, invented ETA or fake progress animation.
- **A**: No icon pack, boxed logo, false proof, decorative SVG or filler graphic. Existing native disclosure/select marks remain meaningful. No blanket icon removal; no new icon is needed for literal job evidence/actions.
- **G**: Responsive fact grid, shared two-column alignment on wide layouts, stacked facts on narrow layouts. Context captures show deliberate gutters. State cells were fixed to stay whole; timestamps/progress scroll intact, detail text wraps. Exact JSON scrolls within its viewport. No added notch/overlap or clipped live text; table horizontal scrolling is deliberate and exercised to the last column.
- **C**: The real job ledger is the artifact: distinct visible short IDs, full selected binding and actual ordered attempt rows, connected to explicit recovery and the retained study. This bounded workbench flow adds no marketing hero/footer/pricing/island skeleton, reused brand world or decorative atmosphere. It serves operational diagnosis within the existing product.
- **P**: Native history and recovery buttons, plain status/fact text and table, no chip around each state, card wrapper, CTA pair, ornamental rail, signup preset or decorative rules. State is communicated by words and a tonal selected history row.
- **R**: Native button/details/table primitives fit the existing vanilla-JS app without a component framework or dependency. Custom behavior is the narrow async/context controller, not a replacement basic widget. Controls expose selected/pending states and a named focusable table-scroll region. Screen-reader output/native zoom remain unverified.
- **S**: Labels distinguish recorded state, current attempt limit, UTC times, failure reason and last check. Missing values stay explicit. Copy states that execution completion is not physical acceptance and retry can run computation again. No fabricated customer metric, decorative quotation or new UI em dash.
