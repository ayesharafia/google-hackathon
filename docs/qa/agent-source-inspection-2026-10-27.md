# Agent source inspection

`sources.list` returns a paginated list limited to the selected project's retained tabular sources. `sources.inspect` checks project ownership, existing user permissions and retained original, manifest and map integrity before returning bounded identity, hashes, declared units, test conditions and sample count. Reuse, import, original-file download, bindings and edits remain outside these actions. The ordinary human-facing library retains its existing cross-project reuse behavior; the agent actions deliberately do not widen a one-project grant.

The targeted suite passed 12 tests: agent scope and pagination, foreign-entry refusal, corrupted source refusal, a real local MCP SDK client calling the new tool, a simulated chat-provider tool call, hosted viewer access, and source-library regressions. Evidence: `.physicore/evidence/AI-SOURCE-001-test-20261027163832078867.json`. The first MCP test run used an incorrect SDK result attribute and was corrected; the first workflow call used system Python 3.9 and was rerun with the project Python 3.11. No real model, live remote client, PostgreSQL deployment or aircraft validation was exercised. Passing these tests does not establish measurement accuracy or installed-aircraft applicability.
