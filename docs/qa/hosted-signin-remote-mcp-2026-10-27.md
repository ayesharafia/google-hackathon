# Hosted sign-in and remote MCP verification

The approved local implementation adds provider authorization-code sign-in with PKCE, browser-bound one-use state and nonce, provisioned issuer/subject matching, opaque hosted browser sessions, and a separate scoped remote MCP access token. Remote transport is disabled without explicit hosted HTTPS configuration. No real provider, paid API call, deployment or aircraft validation was used.

- Broad affected Python run: 193 passed, one PostgreSQL test skipped because the local Docker service was unavailable (`HOSTED-OIDC-001-test-20261027102226438805.json`). The later targeted run also checks remote-cookie denial and a token with multiple audiences (`HOSTED-OIDC-001-test-20261027102332213473.json`). 151 JavaScript tests passed.
- Real official MCP SDK over an in-process HTTPS ASGI transport exercised discovery, read access, two concurrent clients with isolated projects, write approval and idempotent retry, revocation, host validation, request size and separation of remote tokens from app sessions. Synthetic issuer and cryptographic keys were used.
- Actual Chrome against disposable HTTPS and a simulated provider exercised provider redirect, PKCE login, project selection, consent, a remote proposal, human approval, replay-safe receipt sign-out and post-logout remote denial (`HOSTED-OIDC-001-test-20261027102428409415.json`). This is not a live OAuth provider or a real Claude/ChatGPT integration.
- Unit checks cover browser-bound state, concurrent one-use callback, signature, issuer/audience and nonce checks, bad provider endpoint, unknown subject despite matching email, callback replay and cross-origin logout. Build-wheel module/asset hashes were checked. Earlier red tests and a browser harness navigation timing error are retained in task evidence; subsequent runs pass.

Controls were exercised using actual pointer interactions; no entrance animation, glow, decorative icon tiles, fake logos or new font was added. Native browser zoom, screen-reader and user research remain untested.
